# ぷよテト2 のメモリ調査と、全自動のログ集計の道具

2026-11-03 のセッションで使った道具。どれも **ゲームのメモリを読むだけ**(書き込まない)か、TBA のデバッグログ(`../Tetris/debug_logs/`)を読むだけ。
TBA の venv の Python で、`../Tetris` フォルダから実行する(`src.auto.ppt2_memory` を読み込むため)。日本語を出すので `-X utf8` を付ける。

## メモリの調査

| ファイル | 内容 | 使い方 |
|---|---|---|
| `record_player_mem.py` | 1P・2P のプレイヤーのオブジェクトから2段先までの構造体の int32 の変化を、対局が進んでいる間だけ記録する | `python -X utf8 record_player_mem.py <秒> <出力>`(対局していない間は書かないので、長めに回して待てる) |
| `analyze_incoming.py` | 記録から、予告らしい値(ふだん0、ときどき1〜40になって0に戻る)を局ごとに探し、同じ場所で何局に出るかを並べる | `python -X utf8 analyze_incoming.py <記録> HH:MM:SS-HH:MM:SS ...`(局ごとの時間の範囲) |
| `monitor_queues.py` | キューの構造体の候補(たどり方ごと)の中身の変化を記録する(2P のキューを見つけた時の道具) | `python -X utf8 monitor_queues.py <秒> <出力>` |

分かったこと(TBA の `src/auto/ppt2_memory.py` の説明にも書いてある):
- キュー(操作中・NEXT・出てきたミノの数): 1P は (番地は省略) → +(省略)(→ +(省略))→ +(省略)、2P は (番地は省略) → +(省略) → +(省略)。構造体の +(省略) から8バイトずつ7個、+(省略) がミノの数
- 予告(受けているおじゃまの行数): **プレイヤーのオブジェクト(上の +(省略) の手前)の +(省略) の先の +(省略)**、+(省略) から1行ごとの値(6・7 が多い。穴の列かは未確認)。10局すべてで 1P・2P とも同じ
- 予告は、攻撃が届いてから一瞬(75ms ほど)で0に戻ることが多い(すぐ次のミノを固定してせり上がる)。手の合間に1回読むだけでは見逃す

## 全自動のログ集計(TBA のデバッグログ)

| ファイル | 内容 |
|---|---|
| `log_misplacements.py` | 画面との食い違いごとに、直前の手・予定にだけあるマス・画面にだけあるマスを並べる |
| `log_preinput_effect.py` | 先行入力を使った手と使わない手の、ミノが出てからの時間を比べる |
| `log_move_time_trend.py` | 一手の時間の内訳(待ち・思考・入力・出現待ち)が対局の進み方でどう変わるか |
| `log_clear_moves.py` | ラインを消した手の割合と一手の時間 |
| `log_stalls.py` | 手の数ごとに、待った秒数・考え直し・食い違いの回数 |

使い方: `python -X utf8 <道具> debug_logs/debug_log_YYYYMMDD_HHMMSS.txt [debug_log_..._2p.txt]`

置いた位置の確認(手ごと)の集計は、ログの「置いた位置の確認」「これまで 合っていた N手・無かった M手」を grep するのが早い。
